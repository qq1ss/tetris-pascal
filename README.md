# Tetris Pascal

A classic Tetris game written in **FreePascal**.
## Prerequisites
To build and run this game, you need the **FreePascal Compiler (FPC)**.
## Build and Launch

1. **Navigate to the directory:**
    
    Bash
    
    ```
    cd tetris-pascal
    ```
    
2. **Compile the project:**
    
    Bash
    
    ```
    fpc main.pas
    ```
    
3. **Run the game:**
    
    Bash
    
    ```
    ./main
    ```
    

## Controls

| **Key**                 | **Action**   |
| ----------------------- | ------------ |
| **Left / Right Arrows** | Move piece   |
| **Q/E**                 | Rotate piece |
| **Down Arrow**          | Hard Drop    |
| **Space**               | Pause        |
| **Esc**                 | Exit Game    |
